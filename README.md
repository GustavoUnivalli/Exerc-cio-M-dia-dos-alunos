# Exerc-cio-M-dia-dos-alunos
Neste código meu objetivo era colher notas de até 5 estudantes, aos quais cada um teria três notas, a média destas notas e sua situação de aprovação, e todas essas informações deveriam ser apresentadas em forma de tabela, juntamente no final com a informação de qual estudante teve a maior média.
